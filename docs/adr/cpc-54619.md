## Reviewed semantic target

- Canonical PCR: `pcr.constructions-and-construction-services.construction-services.indoor-cat6-utp-permanent-link-installation-services`.
- Included product: First installation of a fixed indoor four-pair Cat 6 UTP solid-copper permanent link from one existing patch-panel carrier port to one existing work-area outlet carrier. Dry manual cable placement uses an accepted prepared accessible pathway; both ends receive compatible tool-free insulation-displacement jack assemblies. The installer labels, tests the permanent link, corrects defects and hands over the accepted link with its actual configuration and test file. Leviton Atlas-X1 61UJK illustrates the jack interface, without making a brand a category requirement. [leviton-atlasx1-utp]
- Excluded adjacent products/routes: Exclude new trays, ducts, penetrations, racks, panel/outlet carriers and building works; old-link removal; shielded, fibre, coaxial, outdoor or inter-building routes; splices, consolidation points and plug-terminated MPTL; equipment/patch cords; active devices, network configuration, PoE load testing and operation. A separately purchased pathway or carrier construction service is an upstream interface, not a hidden installation input. Work needing chemical pulling aids, drilling or different termination technology requires a reviewed scope change.
- Actual route: Receive matched cable, jacks and accessories; accept prepared pathway/carriers and disconnected interfaces; dry-place cable without exceeding its actual bend/tension limits; terminate both jacks with declared pair pattern; mount and label; certify using the selected Cat 6 permanent-link limits and suitable adapters; repair/retest; accept and issue the as-built/test record.
- Starting condition: Accepted existing accessible path and carrier ports; communications interfaces disconnected; actual supplies received
- Handover/market state: Accepted indoor Cat 6 UTP permanent link at installer handover
- Acceptance quality: Selected Cat 6 permanent-link limits passed, original test evidence retained, defects closed and signed handover
- Reference convention: One accepted complete same-configuration link; actual D independently established before normalization; One receipt-to-acceptance job, including actual corrective work and retests; separately indexed resource-life and reporting periods.

The relation is **narrower**: this stated product, starting condition, actual route and acceptance gate form one semantic subset of the official leaf. The decision does not extend the PCR to the leaf’s other technologies, asset states or broader construction responsibilities. Each consumer must check the required qualifiers and excluded responsibilities in the canonical PCR; a classification code alone cannot select an actual project boundary.
