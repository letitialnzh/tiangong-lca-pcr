# CPC 03121 mapping decision

Status: accepted after main-agent semantic review; the PCR remains candidate, not published.

Classification: CPC 3.0 03121 — Roundwood of non-coniferous wood, sawlogs and veneer logs.

Proposed target: `pcr.agriculture-forestry-and-fishery-products.forestry-and-logging-products.roundwood-of-non-coniferous-wood-sawlogs-and-veneer-logs`.

Accepted relation: exact. Acceptance concerns semantic classification equivalence, not publication readiness.

## Semantic decision evidence

UNSD product explanation (https://unstats.un.org/unsd/classifications/Econ/Structure/Detail/EN/2100/03121) includes non-coniferous roundwood intended for sawnwood, sleepers or veneer, roughly squared roundwood, shingle/stave bolts, match billets and burls/roots specifically for veneer. PCR boundaries cover these actual forms and intended uses, not merely conventional straight logs. Exclude finished sawnwood/veneer, treated goods, conifer wood and pulp/panel/other-use/fuel reference allocations. The actual destination, not shape alone, disambiguates neighboring categories.

The declared gate is one forest-roadside producer handover. The reference is 1 kg as-received wood with actual bark/moisture/grade/species and same-lot mass/volume evidence. Biological/source responsibility, harvest/removal, extraction, actual primary preparation and intended-use grading are distinct responsibility interfaces; combined operations are counted once. Natural/managed/plantation/coppice origin, selective/final cuts, special veneer root/burl collection and technology differences require actual records, not universal defaults.

Independent material-category need: non-coniferous species and these intended uses are not interchangeable with conifer roundwood or with pulp/panel/other-use methodology identities. Classification code remains mapping context rather than canonical directory identity.

## Review findings to resolve or retain candidly

Reference product UUID is not confirmed; do not substitute the verified other-use non-conifer UUID or a finished/modified wood row. ## Decision

Accept CPC 3.0 03121 as an exact edge to this material candidate: raw non-coniferous saw/veneer roundwood and the explicitly included special forms are covered at roadside handover; adjacent intended uses and downstream finished products are excluded. Reviewer/time in frontmatter match the mapping edge. See the final round review for lifecycle, target lint, repository validation and coverage readback.
