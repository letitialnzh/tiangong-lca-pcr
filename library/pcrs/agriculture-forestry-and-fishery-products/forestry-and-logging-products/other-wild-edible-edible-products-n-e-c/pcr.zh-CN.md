# 其他未另分类的野生食用产品

## 1. 范围与适用性

本 PCR 覆盖从未受种养管理的来源采集、且未另列明的食用产品，不再仅限于叶菜。叶、嫩梢、茎、花、根／块茎、非浆果果实、种子及其他食用部位或产品，在排除更具体分类后可纳入。这些例子不构成自动归类结论，也不是可互换的食物。记录实际食用物种／部位、野生来源状态、入场状态、验收规格和初级生产者／采集者交付。

排除有意栽培或种养管理的食用生产、有专属子类的野生坚果／蘑菇／松露／浆果、动物／渔业产品及其他已另分类商品，以及归入本初级类别以外的熟制、发酵、提取或其他加工食品。汁液、香辛料、药用产品或种子不能仅因可食用就纳入，须先核对具体类别。商业保藏改变分类时须使用其他适用 PCR，不得默默扩大本类。

这是类别级数据生产方法，不是一种可互换商品或一条平台流。每份前景数据集须声明一种相容产品／状态／门口或有计量组成；不默认混合不相容产品和路线。数量、等级、处理配方及具体身份来自实际案例。

这些是明确声明的聚合清单节点。source 内的管理生产／收获或野生采集为一个明确自有责任，同一份材料不得两者兼有。prepare 负责物理清理／分离及等级出口；treat 仅负责实际状态干预和贮存；assemble 仅适用于合格装饰组合品。一个实际作业只有一个归属。旁路将真实前序输出／接收关联到下一活动节点，包括直接接收至 dispatch；最终交付仍必须保留。即便在一个节点报告，各底层活动仍分开采集。

### 计算规则

| rule_id | Applies to | Formula or rule | Inputs | Output | source_ids |
| --- | --- | --- | --- | --- | --- |
| `normalize_lot` | 所有清单行 | 对各相容交换 i，amount_i = attributable_quantity_i / accepted_net_kg。使用同一验收产品／状态及批次／期间；参考数量为 1 千克。保留分子总量及其归属记录。 | attributable_quantity_i; accepted_net_kg; cp_reference | 原生交换单位／kg 参考产品 |  |
| `substrate_moisture` | 仅限计量植物基材 | dry_substrate_kg = wet_substrate_kg * (1 - water_fraction_wb)；water_fraction_wb = water_kg / (water_kg + dry_substrate_kg)。若干基 water_ratio_db = water_kg / dry_substrate_kg，则 water_fraction_wb = water_ratio_db / (1 + water_ratio_db)。要求干基材为正且 0 <= water_fraction_wb < 1；声明方法及采样。不得将这些式子用于留存处理药剂或非植物组件。 | wet_substrate_kg; water_kg; measured composition; moisture method | 声明干基材与含水基准 |  |
| `node_stock_balance` | 各物理材料台账、节点与期间 | balance_gap = opening_stock + incoming_mass + evidenced_added_mass - closing_stock - intended_exits - waste_exits - environmental_returns - independently_evidenced_releases。明确组成／水分及实际反应或碳边界，确保各项不重叠；实际存在额外来源时计入。记录不确定性并调查差额，不自动把它转成排放。 | dated quantities; material composition; stocks; independently evidenced release records | 质量平衡及未解释差额 |  |
