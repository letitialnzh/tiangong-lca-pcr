# 鲜态未加工野生食用叶菜

## 1. 范围与适用性

本 PCR 覆盖从未经人为经营的陆地来源采集、并在实际初次采集者或整理者交接点交付的鲜态未加工叶片及声明可食嫩叶梢。每个批次均须证明物种、预期利用部位、食用资格、野生来源及验收条件。仅有商业“野生”标签不足以证明来源。作为农作物有意种植或经营的材料不属于该边界。

这是叶菜的窄范围方法学，不是其他野生食品的总括规范。排除坚果、蘑菇、松露、浆果、根、块茎、树液、树胶、昆虫、动物产品、水生藻类、仅药用、仅香辛用途或观赏材料、栽培叶菜，以及烹煮、焯烫、干燥、冷冻、发酵或提取产品。逐一核实预期物种与部位不属于其他更明确的分类。未加工描述市场状态，不代表可直接食用安全：声明后续安全使用所需的准备处理；该处理仍在鲜态初级边界之外。不得将历史民族植物学实例转为普遍物种验收或安全结论。

前景数据包须采用真实行程、批次、场址、物种与部位、操作及验收记录。条件性作业可依据实际记录旁路，但最终验收总须发生。未知作业、来源、损失或验收状态是缺口，不能默认零或未启用。

| `validate_attribution` | 场址、输出、时期与资产 | 核实作业期全部场址、含无收获行程的行程、输出交接点、报告时期、库存结转与共享使用方；确保因果份额完整且有优先顺序，无遗漏或重复记录、包含式服务或销售转移。 | |
| `validate_units_identity` | 具体交换 | 每个具体交换须具有核实身份及兼容属性、单位、供应者、状态、去向。保留原始能源或服务单位、有证据换算及未确认支持的披露；语义总括卡不是固定数据集交换。 | |
| `validate_ranges` | 每张卡 | 每张卡均有数量范围。除参考归一化外，本轮宽泛推理筛选是暂定非强制内容，不以零替代未知、不限制实测值，也不提供可直接发布的经验产率。 | |
