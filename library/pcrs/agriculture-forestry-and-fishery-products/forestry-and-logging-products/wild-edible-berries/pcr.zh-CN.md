# 野生食用浆果——鲜整粒初级交接

## 1. 范围与适用性

本记录涵盖从无管理陆地来源采集、在具名初级采集者/备制者交接关口验收、带物种限定的鲜整粒食用浆果。采集、备制及暂存责任属于产品特定前景采集要求，不是栽培模型。商业名称为野生的浆果仍可能受有意管理；资格由来源证据而非销售名称决定。本类别不含受作物管理的低丛蓝莓、有意栽培浆果、干燥/冷冻商品、果酱、果汁、果泥、烹煮或化学保藏食品及零售配送。

| --- | --- | --- | --- |
| `validate_origin` | 来源及参考流 | 要求物种/食用资格、无管理来源管理证据、场址/采集季/批次、实际初级关口及成熟度/等级/含水声明。野生营销名、森林位置或合法通达本身不充分；未知来源保留为缺口。 | `unsd-cpc3-wild-berries`; `umaine-managed-wild-blueberries` |
| `validate_mass` | 所有清单行 | 所有行共用同一验收最终批次净重分母；参考输出为 1 kg，排除皮重/杂物及其他商品。逐节点核对来料、浆果、拒收物、收集汁液、已识别含水变化及库存；未解释差值是数据缺口，不是零或虚构水蒸气。 |  |
| `validate_route_handoffs` | 过程及等级输出 | 证明各激活/绕过过程及每个输出目的地。保留实际中间质量，映射重新分级/退回循环而不重复最终商品。拒绝加工或冷冻参考状态；声明实际条件，不推定通用鲜态暂存工况。 |  |
| `validate_attribution` | 行程、场址、期间及基础设施 | 检查完整贡献者清单及物种/采集季/关口兼容性、来源贡献权重、失败行程、换批、资产期间、库存、更换和所有输出份额。分配记录求和应回到原始计量总量；记录排除项及代表性局限。 |  |
| `validate_exchanges` | 所有具体交换 | 生成最终交换前解决实际材料/服务/物质、流类型、关口/供应方/目的地、属性及单位。核实固定 UUID 详情和支持行；语义合并项不是具体 UUID。保留综合服务边界及具体直接排放证据。 |  |
| `validate_ranges` | 所有暂定筛选 | 除 1..1 参考归一化外，每项 Range 均为宽泛暂定推理筛选区间，并非观测数据、替代默认值、限制或拒收阈值。超范围触发证据审查，不得截断。零值要求记录未激活/无交换；未知属于缺失。 |  |
